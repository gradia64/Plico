Plico can now tell when a newer version is out, and fixes the AppImage icon
and a signing corner case.

## What's new

- **Help → Check for Updates…** asks GitHub whether a newer version exists
  and opens its page. In *Settings* an automatic check can be turned on, at
  most once a day: it is **off** until you turn it on, and without it Plico
  connects to nothing. It is meant for installs nobody else updates
  (AppImage, `.deb`, pip); the AUR package is updated by pacman, and in the
  Flatpak, which stays offline, the command opens the releases page.

## Fixes

- **AppImage**: Plico's own icon shows in the system tray and on the window,
  instead of the generic PDF one.
- **Signing**: a certificate valid only from a future date is rejected right
  away in the dialog, instead of making the save fail.
- **AUR**: `qt6-translations` among the optional dependencies, so that OK,
  Cancel, Yes and No appear in the interface language.

## Packages

- **AppImage** (`Plico-0.1.6-x86_64.AppImage`), **Debian and Ubuntu**
  (`plico_0.1.6_amd64.deb`), **Flatpak** (`Plico-0.1.6-x86_64.flatpak`) and
  **Arch Linux** (`plico` in the AUR, or
  `pacman -U plico-0.1.6-1-any.pkg.tar.zst`), as in 0.1.5.
- **Verification**: `SHA256SUMS` and, for every file, a GitHub provenance
  attestation: `gh attestation verify <file> -R gradia64/Plico`.
