A new icon, packages for Debian, Ubuntu and Arch Linux, and a security
update: users of the 0.1.4 AppImage or Flatpak should upgrade.

## Security

- **certifi 2026.10.19** in the AppImage, the `.deb` and the Flatpak. The
  version in 0.1.4 trusted the emSign roots, whose intermediate keys have been
  compromised
  ([GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)).
  These are the authorities Plico checks certificates against when it signs
  and verifies. The Arch package uses the system's `python-certifi`.

## Packages

- **Debian and Ubuntu** (`plico_0.1.5_amd64.deb`): the same content as the
  AppImage, installed in `/opt/plico` with its menu entry and icon;
  `sudo apt install ./plico_0.1.5_amd64.deb`. Requires glibc 2.34 or later
  (Debian 12, Ubuntu 22.04 or newer); it does not update itself.
- **Arch Linux**: the AUR package `plico` (`paru -S plico`, or another
  helper) is built from the signed tag, which `makepkg` verifies with the
  release key; the prebuilt one is among the assets
  (`pacman -U plico-0.1.5-1-any.pkg.tar.zst`).
- **AppImage** (`Plico-0.1.5-x86_64.AppImage`) and **Flatpak**
  (`Plico-0.1.5-x86_64.flatpak`), as in 0.1.4.
- **Verification**: `SHA256SUMS` and, for every file, a GitHub provenance
  attestation: `gh attestation verify <file> -R gradia64/Plico`.

## What's new

- **New icon**: two sheets and a pencil on a midnight-blue plate, readable
  even at 16 pixels.
- **CHANGELOG.md** in the repository, covering every version since 0.1.0.
