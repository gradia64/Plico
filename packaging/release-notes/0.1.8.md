Plico 0.1.8 brings fixes from a penetration test of 0.1.7 and a new AppImage for ARM64.

## What's new

- **AppImage for ARM64** (`Plico-0.1.8-aarch64.AppImage`), for Raspberry Pi 4 and 5, Snapdragon laptops and Asahi Linux. Requires glibc 2.39 or later (Debian 13, Ubuntu 24.04, Fedora 40 or newer), because Qt's libraries for ARM require it. The same versions of Qt, PyMuPDF, pikepdf and pyHanko as the x86_64 AppImage.

## Security

- **Password-protected PDFs**: saving (even compressed or signed) over a protected file rewrote it in plain text without saying so. Now the file stays encrypted (AES-256) with the password used to open it and the same permissions. "Save as" on a new file writes, as before, an unprotected file.
- **Deletion of vertical or rotated text**: "Delete word…" and word selection removed only a few letters of a word written vertically or diagonally; the rest stayed in the file, extractable. Now it all disappears.
- **Signed documents**: a signed file without the `/SigFlags` flag was taken for unsigned, and saving removed the signature without asking. Now the signature is recognised from the fields.
- **Temporary files**: during saving and compression the document passed through a file readable by other users, if the folder was. Now temporaries live in a folder only the user can open.
- **Documents built to block Plico**: Plico now opens at most 20,000 pages (even merging documents) and does not read the fields of a page that has more than 1,000.
- **Document text shown as text**: file and field names, error messages and the name in a signature certificate are no longer interpreted as HTML (a PDF could make a fake "Valid signature" or a clickable link appear).
- **Trusted certificates**: Plico keeps a copy in its own folder instead of re-reading the chosen `.pem` file every time.
- **Update check**: malformed responses give "Invalid GitHub response" instead of an internal error.

## Packages

- **AppImage** (`Plico-0.1.8-x86_64.AppImage` and, new, `Plico-0.1.8-aarch64.AppImage`), **Debian and Ubuntu** (`plico_0.1.8_amd64.deb`), **Flatpak** (`Plico-0.1.8-x86_64.flatpak`) and **Arch Linux** (`plico` in the AUR).
- **Verification**: `SHA256SUMS` and, for every file, a GitHub provenance attestation: `gh attestation verify <file> -R gradia64/Plico`.
