Plico 0.2.0 adds annotations, a bookmarks panel, printing and password protection, and brings the fixes from two reviews of 0.1.8.

## What's new

- **Annotations** (_Annotate_ menu): Highlight (`Ctrl+Shift+H`), Underline (`Ctrl+Shift+U`) and Strike Out (`Ctrl+Shift+K`) on the words you drag over, a Note with one click, and Freehand Drawing. They stay editable until you save (a click with the tool on removes one, `Ctrl+Z` undoes it), then become real PDF annotations that other readers show and edit. An annotation that touches an erased area is deleted with it.
- **Bookmarks panel** (_View → Bookmarks_, a tab next to the thumbnails): shows the PDF's outline, jumps to a page with one click, and lets you add, rename, move, nest and delete entries. Every change can be undone, and saving writes the outline as shown. Merging a PDF appends its bookmarks.
- **Print** (_File → Print…_, `Ctrl+P`): prints the document as it would be saved (deleted pages, rotations, forms, corrected text and erased areas included), even before saving. All pages, a range or the current page; landscape pages on portrait paper are turned. If a PDF forbids printing, Plico says so and prints only after you confirm.
- **Protect with Password** (_File → Protect with Password…_): saves with a password of your choice (AES-256) and, if you wish, without permission to print, copy or modify, with an optional owner password (a random one is created when a restriction is set without it). On a protected file, "No password" removes it.
- **Duplicate Page** (`Ctrl+D`), **Insert Blank Page** (the size of the chosen page) and **Crop Margins** (_Edit → Crop Margins…_: margins in millimetres as seen on screen, for one page or all of them, or detected from the content). Cropping hides, it does not delete: what is left outside stays in the file, and the dialog says so.

## Security

- **PDFs with only an owner password** (they open without asking but restrict printing, copying or editing): saving rewrote them in plain text, without permissions. Now they stay encrypted with the same permissions; Plico asks for the owner password at the first save, and creates a random one if you leave it empty. Signing them as they are on disk now works too.
- **"Save as" over a protected PDF that is not the open one** replaced it with an unprotected file without warning. Now Plico asks first (also for "Save Compressed", "Sign" and "Extract Pages").
- **Signatures outside the pages**: a signature field present in the form but on no page was not seen, and saving removed the signature without asking. Now it counts.
- **Signing a document with thousands of fields** froze the window; choosing the name of the signature field is now linear.
- Error messages of the signature dialog and the compression and OCR summaries always show plain text, never markup.

## Fixed

- **Every save dropped bookmarks, title, author and page numbering** (for example "i, ii, iii" in a preface): rotating one page and saving was enough. Now they stay, also when merging and extracting pages; bookmarks follow their pages and go only with deleted ones. When an area is erased, title, author and bookmarks are not copied, because they might contain the removed text, and the confirmation says so.
- After saving, compressing or signing over a protected PDF, reopening asked for the password again, and cancelling closed the document. Now the password already given is used.
- Compressing a protected PDF measured the gain before encryption and could announce a saving for a file that grew. Now it compares with the encrypted file it replaces.
- A write error while saving a trusted certificate was not reported as an error.
- The "About Plico" window always has its OK button and is freed when closed.

## Packages

- **AppImage** (`Plico-0.2.0-x86_64.AppImage` and `Plico-0.2.0-aarch64.AppImage`), **Debian and Ubuntu** (`plico_0.2.0_amd64.deb`, which now depends on libcups for printing), **Flatpak** (`Plico-0.2.0-x86_64.flatpak`, with access to CUPS) and **Arch Linux** (`plico` in the AUR).
- Using the system PySide6 on Debian or Ubuntu, printing needs `python3-pyside6.qtprintsupport`.
- **Verification**: `SHA256SUMS` and, for every file, a GitHub provenance attestation: `gh attestation verify <file> -R gradia64/Plico`.
