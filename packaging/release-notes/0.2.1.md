Plico 0.2.1 lets you remove the annotations a PDF already has and rewrite its notes.

## What's new

- **Annotations already in the PDF**: with an _Annotate_ tool on, a click removes an annotation the file already had (highlights, notes, shapes, drawings), as it does for those made in Plico. A right-click on any annotation opens **Edit Note…** (for notes) and **Remove Annotation**, even with no tool on; notes made in Plico are rewritten the same way. Everything undoes with `Ctrl+Z` and reaches the file only when you save, while the page and the thumbnails show the result at once. Links and form fields are not touched.

## Changed

- The release and Flatpak workflows run their actions on Node 24.
- Test messages are in English, like the rest of the test code.

## Packages

- **AppImage** (`Plico-0.2.1-x86_64.AppImage` and `Plico-0.2.1-aarch64.AppImage`), **Debian and Ubuntu** (`plico_0.2.1_amd64.deb`), **Flatpak** (`Plico-0.2.1-x86_64.flatpak`) and **Arch Linux** (`plico` in the AUR).
- **Verification**: `SHA256SUMS` and, for every file, a GitHub provenance attestation: `gh attestation verify <file> -R gradia64/Plico`.
