The first Plico release with ready-to-download packages. The application is
the same as 0.1.3: what changes is how it is distributed and how tags are
signed.

## Packages

- **AppImage** (`Plico-0.1.4-x86_64.AppImage`): a single file bundling Python,
  Qt, PyMuPDF and the OCR language data (Italian, English, French, German,
  Spanish). Make it executable and run it; requires glibc 2.34 or later
  (Debian 12, Ubuntu 22.04, Fedora 35 or newer).
- **Flatpak** (`Plico-0.1.4-x86_64.flatpak`): for those who want the sandbox,
  with no access to the home folder (files go through the portal). `flatpak
  install --user Plico-0.1.4-x86_64.flatpak` downloads the KDE runtime it
  needs from Flathub. It does not update itself.
- **Verification**: `SHA256SUMS` and, for every file, a GitHub provenance
  attestation: `gh attestation verify <file> -R gradia64/Plico` checks that
  the file was built by this repository's CI from this tag.

## What Plico does

- **Pages**: rotate, delete, reorder by dragging, merge PDFs and images,
  extract pages, create a PDF from photos and scans.
- **True redaction**: the content under an area leaves the file, it is not
  just covered; a preview of the document as it will be saved, and a
  confirmation before writing.
- **Forms, text, OCR, signatures**: fill AcroForm fields, fix a line of text
  where it is, make a scan searchable, sign in PAdES and verify signatures.
- **Search** with `Ctrl+F`, **Settings** (interface language, tray icon), a
  **help** guide in five languages with `F1`.

## Technical notes

- **Tags signed with the Plico release key** (OpenPGP): primary
  `1843 07C7 A158 5AFA D7F0  9DF6 EBC8 B4A0 FFD5 B91F`, tag-signing subkey
  `E0C7 71BB B276 A114 D0B8  C591 C5DD C074 5643 FA72`; the public key is
  `packaging/plico-release-key.asc`. Tags up to `v0.1.3` were signed with an
  SSH key.
- **Automated releases**: `release.yml` verifies the tag signature, builds the
  packages, runs the full test suite against the AppImage's libraries and
  publishes after the maintainer's approval.
- **Not on Flathub**: its policy on generative AI excludes manifests written
  with AI assistance, and Plico uses a lot of it (code, tests, documentation,
  packaging).
