Plico Handbook

Plico is a PDF editor: it rotates, deletes and reorders pages, merges files, really removes confidential data, fills in forms, makes scans searchable and signs documents. The original file is never touched until you save.

Opening and merging

File → Open… (Ctrl+O) opens a PDF. A password-protected file asks for it before opening. You can also open a PDF by double-clicking it in the file manager.

File → Merge PDF… (Ctrl+Shift+M) appends the pages of another PDF, or of an image: a photographed receipt becomes the last page. Merged pages are moved, rotated and deleted like the others, and one Ctrl+Z undoes the merge.

Pages

On the left is the thumbnail bar: a click brings the page into view, dragging changes the order.

  • Rotate Right (Ctrl+R) and Rotate Left (Ctrl+Shift+R) turn the selected page by 90°.
  • Edit → Delete Page (Del) removes it.
  • File → Extract Pages… (Ctrl+E) writes part of the document to a new file. Pages are written like 1-3,5,8; commas and blanks separate alike, so 1 3 is pages 1 and 3. The typed order is the order of the new file: 5,1-3 puts the fifth page first.

Everything is undone with Edit → Undo (Ctrl+Z) and redone with Ctrl+Y; the «History» panel shows the steps taken. Zoom is in the View menu: Ctrl++, Ctrl+- and Ctrl+0 to fit the width.

Creating a PDF from images

File → Create from Images… (Ctrl+Shift+N) turns photos and scans (PNG, JPEG, TIFF, BMP, GIF) into a PDF, one page per image, in the order chosen. A scan keeps its real size, a phone photo becomes an A4. The document starts as «Untitled»: with Ctrl+S Plico offers to save it next to the first image.

Saving

  • File → Save (Ctrl+S) writes to the open file.
  • File → Save As… (Ctrl+Shift+S) asks where.
  • File → Save Compressed… (Ctrl+Shift+C) writes a lighter copy. Light loses nothing; Medium and Strong resample over-detailed images (to 150 and 96 dpi). The work can be limited to the images or to some pages. Plico shows what it really gained, and if there is nothing to gain it writes nothing.

Saving always goes through a temporary file: if something goes wrong, the original file stays as it was. The window title marks unsaved changes with *, and closing or opening another file asks before losing them.

Finding

Edit → Find… (Ctrl+F) opens a bar under the page. Every match is highlighted, the current one in orange; Enter or F3 goes to the next, Shift+F3 to the previous, Esc closes the bar. The search also finds words just recognized by OCR, before saving.

Erasing data

Erasing in Plico means taking the content out of the file, not covering it with a black rectangle: what goes can no longer be copied or searched. The notes and form fields the area touches go with it. There are three ways:

  • Erase Area (Ctrl+Shift+X): drag a rectangle over the content to remove. The corners of an area resize it, the centre moves it, a click removes it.
  • Erase Selection (Ctrl+Shift+L): drag over the words, which are always taken whole.
  • Erase Word… (Ctrl+Shift+F): a word searched on every page, every occurrence in one go.

While the tool is on, the areas are dark rectangles to correct. As soon as you turn it off (Esc) the page and its thumbnail show the preview: the document as it will be saved. The title counts the removals still to apply, and before writing the file Plico asks for confirmation with the number of areas and the pages. Until then everything is undone with Ctrl+Z.

Correcting text

Edit → Edit Text (Ctrl+Shift+T): a click on a line opens it in a small editor over the page. Enter confirms, Esc cancels. The new text takes the place of the old one with the same size and colour, and with the same font when it is installed. It is meant for short corrections, one line at a time.

Filling in forms

If the PDF is a form, its fields are highlighted on the page: a click on a field opens it for typing. The «Form» panel lists the fields of the current page: text, check boxes, drop-down lists and multiple choices. The values go into the file when you save, and are undone with Ctrl+Z.

Recognizing the text of a scan

A scan is a picture: its text can be neither searched nor copied. Edit → Recognize Text… (Ctrl+Shift+O) reads it and adds an invisible text layer under the image: the page looks the same, but the text becomes selectable and searchable. You write the pages to read as in Extract Pages, for example 3, 4-8 or 1-3,5 (all of them are proposed when it opens), and choose the language of the document. At the end a notice over the page says on how many pages it found text.

Signing and verifying

File → Sign… (Ctrl+Shift+D) signs the document with a personal certificate in PKCS#12 format (.p12 or .pfx) and its password. You can add a reason, a location and a visible box on a page. The signature covers the saved file: any later change voids it, and Plico warns before removing it.

File → Verify Signatures… tells for each signature whether the document is intact and who signed it. A certificate is considered trusted only if you add it yourself, as a .pem file, with the dialog's button: Plico does not decide on its own whom to trust.

Settings

Settings → Configure Plico… (Ctrl+Shift+,):

  • Language: automatic (the system's) or Italian, English, French, German or Spanish. If the system language is not among these, Plico uses English. The new language applies from the next start.
  • Notification area: a Plico icon next to the clock. With the icon you can also choose that the window's X minimizes Plico to the notification area instead of closing it: a click on the icon reopens the window, and you quit from File → Quit (Ctrl+Q) or from «Quit» in the icon's menu.
  • Updates: a daily check for new versions, off until you turn it on (see below).

Updates

Help → Check for Updates… asks GitHub which is the latest version of Plico and tells you whether there is a newer one, with a button that opens its page. It is the only network request Plico makes, and it goes out only when you ask: it sends nothing about you or your documents.

In Settings → Configure Plico… you can have Plico check by itself, at most once a day: the box stays unchecked until you tick it. When a new version comes out, a note over the page says so once, and Help → Download Plico stays in the menu until you update.

It depends on how you installed Plico: the AppImage and the .deb package do not update themselves, and the daily check is there for them. The AUR package is updated by the package manager, so the box is not offered there. The Flatpak package has no network access: the command opens the releases page in the browser, to compare it with yours.

Where the files are

Installed as a Flatpak, Plico does not see the home folder by itself: every file goes through the system's file chooser, and Plico can read and write only the ones you pick there, or open with a double click. It is a protection, not a limit: the dialogs still offer the real folders.
