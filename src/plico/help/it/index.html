Guida di Plico

Plico è un editor PDF: ruota, elimina e riordina le pagine, unisce più file, cancella davvero i dati riservati, compila i moduli, rende cercabili le scansioni e firma i documenti. Il file di partenza non viene mai toccato finché non salvi.

Aprire e unire

File → Apri… (Ctrl+O) apre un PDF. Un file protetto da password la chiede prima di aprirsi. Si può anche aprire un PDF con un doppio clic dal gestore dei file.

File → Unisci PDF… (Ctrl+Shift+M) aggiunge in coda le pagine di un altro PDF, o di un'immagine: una ricevuta fotografata finisce come ultima pagina. Le pagine unite si spostano, ruotano ed eliminano come le altre, e un Ctrl+Z annulla l'unione.

Le pagine

A sinistra c'è la barra delle miniature: un clic porta la pagina in vista, il trascinamento cambia l'ordine.

  • Ruota a destra (Ctrl+R) e Ruota a sinistra (Ctrl+Shift+R) girano la pagina scelta di 90°.
  • Modifica → Elimina pagina (Canc) la toglie.
  • File → Estrai pagine… (Ctrl+E) scrive una parte del documento in un file nuovo. Le pagine si scrivono come 1-3,5,8; virgole e spazi separano allo stesso modo, quindi 1 3 sono le pagine 1 e 3. L'ordine scritto è quello del file nuovo: 5,1-3 mette la quinta pagina per prima.

Tutto si annulla con Modifica → Annulla (Ctrl+Z) e si ripete con Ctrl+Y; il pannello «Storico azioni» mostra i passi fatti. Lo zoom è nel menu Visualizza: Ctrl++, Ctrl+- e Ctrl+0 per adattare alla larghezza.

Creare un PDF da immagini

File → Crea da immagini… (Ctrl+Shift+N) trasforma foto e scansioni (PNG, JPEG, TIFF, BMP, GIF) in un PDF, una pagina per immagine, nell'ordine scelto. Una scansione mantiene il suo formato reale, una foto da telefono diventa un A4. Il documento nasce «Senza titolo»: con Ctrl+S Plico propone di salvarlo accanto alla prima immagine.

Salvare

  • File → Salva (Ctrl+S) scrive sul file aperto.
  • File → Salva con nome… (Ctrl+Shift+S) chiede dove.
  • File → Salva compresso… (Ctrl+Shift+C) scrive una copia più leggera. Leggera non perde niente; Media e Forte ricampionano le immagini troppo definite (a 150 e 96 dpi). Si può limitare il lavoro alle immagini o a certe pagine. Plico mostra quanto ha guadagnato davvero, e se non c'è niente da guadagnare non scrive niente.

Il salvataggio passa sempre da un file temporaneo: se qualcosa va storto, il file di partenza resta com'era. Il titolo della finestra segna con * le modifiche non salvate, e chiudere o aprire un altro file chiede prima di perderle.

Trovare

Modifica → Trova… (Ctrl+F) apre una barra sotto la pagina. Tutte le occorrenze vengono evidenziate, quella corrente in arancione; Invio o F3 passa alla successiva, Shift+F3 alla precedente, Esc chiude la barra. La ricerca trova anche le parole appena riconosciute dall'OCR, prima di salvare.

Cancellare i dati

Cancellare in Plico vuol dire togliere il contenuto dal file, non coprirlo con un rettangolo nero: quello che sparisce non si può più copiare né cercare. Insieme spariscono anche le note e i campi dei moduli che la zona tocca. Ci sono tre modi:

  • Cancella zona (Ctrl+Shift+X): si trascina un rettangolo sul contenuto da togliere. Gli angoli di una zona la ridimensionano, il centro la sposta, un clic la toglie.
  • Cancella selezione (Ctrl+Shift+L): si trascina sulle parole, che vengono prese sempre intere.
  • Cancella parola… (Ctrl+Shift+F): una parola cercata in tutte le pagine, ogni occorrenza in un colpo solo.

Mentre lo strumento è acceso le zone sono rettangoli scuri da correggere. Appena lo spegni (Esc) la pagina e la sua miniatura mostrano l'anteprima: il documento come verrà salvato. Il titolo conta le cancellazioni ancora da applicare, e prima di scrivere il file Plico chiede conferma con il numero di zone e le pagine. Fino ad allora tutto si annulla con Ctrl+Z.

Correggere il testo

Modifica → Modifica testo (Ctrl+Shift+T): un clic su una riga la apre in un piccolo editor sopra la pagina. Invio conferma, Esc annulla. Il testo nuovo prende il posto del vecchio con lo stesso corpo e lo stesso colore, e con lo stesso font quando è installato. È pensato per correzioni brevi, una riga alla volta.

Compilare i moduli

Se il PDF è un modulo, i campi sono evidenziati sulla pagina: un clic su un campo lo apre per scriverci. Il pannello «Modulo» elenca i campi della pagina corrente: testo, caselle, menu a tendina e scelte multiple. I valori entrano nel file al salvataggio, e si annullano con Ctrl+Z.

Riconoscere il testo di una scansione

Una scansione è un'immagine: il testo non si può né cercare né copiare. Modifica → Riconosci testo… (Ctrl+Shift+O) lo legge e aggiunge sotto l'immagine uno strato di testo invisibile: la pagina resta identica, ma il testo diventa selezionabile e ricercabile. Si scrivono le pagine da leggere come in Estrai pagine, per esempio 3, 4-8 o 1-3,5 (all'apertura sono proposte tutte), e si sceglie la lingua del documento. Alla fine un avviso sopra la pagina dice su quante pagine ha trovato del testo.

Firmare e verificare

File → Firma… (Ctrl+Shift+D) firma il documento con un certificato personale in formato PKCS#12 (.p12 o .pfx) e la sua password. Si può aggiungere un motivo, un luogo e un riquadro visibile su una pagina. La firma copre il file salvato: ogni modifica successiva la annulla, e Plico avvisa prima di toglierla.

File → Verifica le firme… dice per ogni firma se il documento è intatto e chi l'ha firmato. Un certificato è considerato fidato solo se lo aggiungi tu, come file .pem, dal pulsante del dialogo: Plico non decide da solo di chi fidarsi.

Impostazioni

Impostazioni → Configura Plico… (Ctrl+Shift+,):

  • Lingua: automatica (quella del sistema) oppure italiano, inglese, francese, tedesco o spagnolo. Se la lingua del sistema non è tra queste, Plico usa l'inglese. La lingua nuova vale dal prossimo avvio.
  • Area di notifica: un'icona di Plico vicino all'orologio. Con l'icona si può anche scegliere che la X della finestra riduca Plico nell'area di notifica invece di chiuderlo: un clic sull'icona riapre la finestra, e si esce da File → Esci (Ctrl+Q) o da «Esci» nel menu dell'icona.

Dove sono i file

Installato come Flatpak, Plico non vede da solo la cartella home: ogni file passa dalla finestra di scelta dei file del sistema, e Plico può leggere e scrivere solo quelli che scegli lì, o che apri con un doppio clic. È una protezione, non un limite: i dialoghi propongono comunque le cartelle vere.
